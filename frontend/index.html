Key Features

Everything You Need for Digital Document Management

JWT & Bcrypt Security

Passwords hashed with 12 bcrypt salt rounds. Authenticated sessions with signed Bearer JWTs.

Magic Byte Signature Validation

Every uploaded file is inspected at binary level to block malicious file renaming attacks.

SQLite Metadata Persistence

Metadata stored in SQLite database with foreign key enforcement and fast indexing.

Instant Search & Categories

Filter documents by category or search by document title in real-time.

Secure File Downloads

Download your verified original documents safely with sanitized download headers.

Ownership Isolation

Strict database-level checks ensure no user can access, edit, or delete another user's files.

Security Architecture

Zero Trust, Multi-Layered Protection

Binary File Inspection

Every file is validated against strict magic-byte signatures (PDF, PNG, JPG, DOCX, TXT), preventing disguised executables.

Cryptographic Passwords

Passwords hashed with 12 bcrypt salt rounds and session tokens signed with high-entropy cryptographic secrets.

Strict Data Isolation

Foreign-key enforced user boundaries ensure users can only ever access, download, or edit their own documents.
